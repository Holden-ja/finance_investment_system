# 财经投资决策分析系统 v3.0
# Finance Investment Decision Analysis System

## 项目概述

完整的**财经投资决策分析平台**，整合新闻抓取、行业研究、产业链分析、智能选股、投资大师评审，从数据到决策的闭环系统。

---

## 模块说明

### 1. 核心系统 (`finance_investment_system.py`)
**主程序**，包含所有功能：
- 产业链全景图（树状图展示）
- 行业股票分析
- 智能选股评分
- 投资建议报告

### 2. 新闻模块 (`finance_news_system.py`)
- 实时抓取：东方财富、财联社、新浪财经
- 新闻情感分析（利好/利空/中性）
- 行业分类追踪

### 3. 行业研究 (`industry_analysis.py`)
- 8大行业深度分析
- 产业链上下游拆解
- 财务评估

### 4. 投资决策 (`investment_advisor.py`)
- 综合评分模型
- 选股排名
- 生成投资报告

### 5. 投资大师评审 (`investment_with_judges.py`)
- 集成巴菲特/芒格Agent
- 需要配置阿里云API

```
【新能源车】
├── 上游：锂矿→正极材料→隔膜→电解液

└── 下游：整车→充电桩

【AI算力】（从砂子到数据中心）
├── 资源：硅矿
├── 材料：多晶硅→硅片
├── 芯片：设计→制造→封测
├── 组件：光纤→光模块→连接器→散热→存储
├── 整机：服务器→数据中心
└── 电力：算力耗电大户

【电力能源】
├── 上游：煤炭、天然气
├── 中游：水电/火电/风电/光伏/特高压/电网
└── 下游：工业用电、居民用电

【半导体】
├── 上游：硅片→光刻胶→电子气体→靶材
├── 中游：晶圆制造→封装测试
└── 下游：芯片设计→消费电子/汽车电子

【光伏】
├── 上游：多晶硅→硅片
├── 中游：电池片→组件→逆变器
└── 下游：光伏电站

【医药】
├── 上游：原料药→中间体→中药材
├── 中游：化学药→生物药→医疗器械
└── 下游：医院→药店

【白酒】
├── 上游：高粱→包装
├── 中游：高端酒→次高端→中端
└── 下游：经销商→电商

【银行/券商】
└── 吸收存款→对公/零售业务→企业/个人用户
```

## 使用方式

```bash
# 一键运行完整分析
python finance_investment_system.py

# 单独运行各模块
python finance_news_system.py      # 新闻抓取
python investment_advisor.py        # 投资决策
python supply_chain_analysis.py     # 产业链分析
```
